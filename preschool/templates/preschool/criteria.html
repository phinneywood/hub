Search, check, summarize.

  1. The app finds possible messages using the preschool name, class mailing list and tuition clues.
  2. Only current information specific to the {{ school.short_name }} class belongs in these notes. Neighborhood articles and unrelated messages are left out.
  3. When automatic sorting is on, useful dates, tasks, stated class fees and updates can be summarized with a source link. Nothing is paid, sent, RSVP’d or added to Calendar.
